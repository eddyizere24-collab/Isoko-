## WhatsApp Boundary Rule
Buyer-initiated WhatsApp order messages (`buildSingleProductWhatsAppMessage`, `buildCartWhatsAppMessages`) **always remain in Kinyarwanda (`rw`)** regardless of which UI language the buyer selected, because sellers operate in Rwanda.
