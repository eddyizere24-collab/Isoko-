# ISOKO native-speaker translation review checklist

Date prepared: 2026-11-16

## Scope and rules
The Kinyarwanda dictionary (`rw`) is the reference text. English (`en`) is marked reviewed in code, but French, Swahili, Kirundi, Lingala and Luganda remain `reviewed: false` until a native speaker checks each row below. Each row is one user-visible or system translation key in the dictionary. Review spelling, natural phrasing, grammar, local vocabulary, respectful tone, consistency, button length on mobile, and the correctness of placeholders such as `{n}`.

**Do not change the `reviewed` flag until every row for that language has been checked by a qualified native speaker and the reviewer/date are recorded.** Do not show users any beta or unreviewed badge.

Dictionary parity as read on 2026-11-16: all six dictionaries contain the same 155 keys as `rw`; CI also checks this.
