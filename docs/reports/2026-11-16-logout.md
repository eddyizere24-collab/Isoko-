# Logout and account centre report — 2026-11-16

## Changes
- MarketplaceContext waits for Neon Auth signOut, then clears the locally stored account session and private account caches.
- The last private route is replaced with Home in browser history; guest cart, language, location, recents and followed shops are preserved.
- Account-scoped keys in localStorage/sessionStorage and matching Isoko/Neon Auth IndexedDB databases are cleared where the browser supports database enumeration.
- New /konti page shows account identity and email verification status, supports password change when the Better Auth client exposes changePassword, and shows other-device logout only when revokeOtherSessions exists.
- The Konti tab and desktop account link now open /konti for signed-in users.
- Added a storage cleanup unit test.

## Not tested
- No real Neon Auth sign-out/login browser session.
- No password change on a QA account.
- No other-device revocation call was made.
- Browser support for IndexedDB databases() differs; cleanup is guarded where available.
- In-flight Neon SDK Data API operations are not all abortable through the current client wrapper. Components with existing effect guards stop updating after unmount, but full SDK request cancellation remains open.

## Production
No Production database, Auth configuration, Function, Storage, Render environment or deployment was changed.
