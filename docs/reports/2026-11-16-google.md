# Google sign-in package report — 2026-11-16

## Changes
- Added a feature flag `VITE_ISOKO_GOOGLE_SIGNIN_ENABLED`; default is false.
- Added a feature-flagged Google sign-in button to the existing login page using the existing `neon.auth.signIn.social({ provider: 'google', callbackURL })` helper.
- Added tap-only Android instructions in docs/ops/GOOGLE_OAUTH_STEPS.md with the current Production origin and Better Auth callback URI, plus an instruction to verify the callback shown by Neon Console before saving it.

## Not completed / not proven
- The Google provider on Production still has null client ID and secret.
- The flag remains off; there is no Google button in Production.
- The sign-in flow has not been tested on a QA account.
- Google One Tap / account chooser is not implemented; we use the documented Better Auth social redirect path only.
- Seller Google onboarding with only shop name, WhatsApp and terms is not complete or tested.
- Buyer Google email opt-in, consent timestamp, and unsubscribe storage are not implemented.
- Production email verification remains disabled.

## Production
No Neon Auth provider settings, Google credentials, Render env vars, Production DB, Function or deployment were changed.
