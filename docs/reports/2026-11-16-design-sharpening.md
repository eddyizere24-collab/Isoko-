# ISOKO brand clarity and mobile readability

Date: 2026-11-16  
Base: `main` at `1f46194c625537b0b3cbcdc72153a5695d8b2856`

## Changes
- Central palette tokens: `#FAFAF7` page, `#FFFFFF` surfaces, `#1A1F1C` primary text, `#4B544F` secondary text, `#0B6E4F` main action, `#C0392B` accent.
- Central compatibility aliases map older Tailwind colours to those tokens.
- Removed pale cream/green fallback wallpaper; actual seller/product photographs remain intact.
- Imigongo pattern is a crisp repeating `12×12px` SVG tile, `1:1`, with green/red/ochre strokes ≥1.5px.
- Home hero headline and logo are larger, with one 44px solid-green “Fungura iduka” action.
- Category tiles are 96×92px, 40px coloured icons and 11.5px labels.
- Product cards retain three mobile columns, remove the restrictive 185px max-height, and use clearer 18/20/24px price and 13/15px name scales.
- Sun logo keeps the multicolour hollow centre with 12 larger outer beads.
- Added tests for central tokens, WCAG AA contrast and Imigongo geometry.
